# Issues — `hospital_patient_system.py`

Sources: Pylint (5.19/10), Bandit (5 issues: 2 High, 1 Medium, 2 Low), Flake8 (11 warnings), plus problems found by reading the code and running it. Ordered by severity, high and medium first. Severity is shown in the Type column.

| Issue | Type | Line(s) | Description | Fix Approach |
| ----- | ---- | ------- | ----------- | ------------ |
| Shell command injection via `os.system` (Bandit B605) | Security (High) | 56 | `os.system("echo ... " + filename)` builds a shell command from a variable. A filename like `x; rm -rf ~` would run arbitrary commands. The `echo` is also pointless. | Remove `os.system` and use `print(f"Patient ledger exported to: {filename}")`. If a subprocess is ever needed, use `subprocess.run([...], shell=False)`. |
| Weak MD5 hash (Bandit B324) | Security (High) | 45 | `hashlib.md5` is cryptographically broken. Patient identifiers are sensitive, and an MD5 of a short ID like `P103` is trivially reversible by brute force. | Use `hashlib.sha256`, ideally with a per-system salt or `hmac`. If it is only a non-security checksum, pass `usedforsecurity=False`. |
| Hardcoded secret, printed to stdout (not flagged by any tool) | Security (High) | 68, 77 | `nurse_access_key = "HOSPITAL_NURSE_MASTER_KEY_2026"` is committed in source, and `main()` prints it to the console. Anyone with repo or log access gets the master key. | Read it from an environment variable (`os.environ.get("NURSE_ACCESS_KEY")`) and never print it. Remove the print. |
| Use of `eval` on caller-supplied expression (Bandit B307, Pylint W0123) | Security (Medium) | 40 | `eval(formula_expr)` executes arbitrary Python, so a malicious `formula_expr` can run any code. | Replace with `ast.literal_eval` for literals only, or take a numeric `multiplier` argument and compute `base_bill * multiplier`. Alternatively use a whitelist of named pricing formulas. |
| Mutable default argument `intake_log=[]` (Pylint W0102) | Bug (Medium) | 13, 17 | The default list is created once and shared across all calls, so state leaks between calls. It is also never returned or stored, so the intake log is lost. | Use `intake_log=None`, then `if intake_log is None: intake_log = []`. Return or store the log if it needs to be kept. |
| Bare `except` with `pass` swallows errors (Flake8 E722, Pylint W0702, Bandit B110) | Bug / Code Quality (Medium) | 24–25 | Catches every exception, including `KeyboardInterrupt`. Discharging an unknown patient ID fails silently, so the caller thinks it succeeded. | Catch `KeyError` only, and return `False` (or raise/log) when the patient is not found. Return `True` on success. |
| Patient data exported in plaintext as a Python `repr` | Security / Bug (Medium) | 52–55 | `str(patient_records)` writes all names, wards and bills to an unprotected file. The format is not a parseable file format (Python repr, not JSON). | Write with `json.dump(..., indent=2)` and restrict file permissions. Document that the file contains PII, or omit unneeded fields. |
| `calculate_treatment_cost` crashes on unknown patient and never saves the result | Bug (Medium) | 38–41 | `patient_records[p_id]` raises `KeyError` for an invalid ID. The computed total is returned but never written back to the patient's `bill`. | Check `p_id in patient_records` first and return `None` or raise a clear `ValueError`. Update `bill` if the intent is to persist it. |
| File opened without `with` or encoding (Pylint R1732, W1514) | Code Quality / Bug (Low) | 53–55 | `open()` followed by manual `close()` leaks the handle if `write` raises. No encoding is specified, so behaviour depends on the OS. | `with open(filename, "w", encoding="utf-8") as f:` and write inside the block. |
| Non-cryptographic `random` used for a token (Bandit B311) | Security (Low) | 49 | `random.randint(1000, 9999)` is predictable and only has 9000 values, which is unsuitable for an access or ward token. | Use `secrets.randbelow` / `secrets.token_hex`, and widen the range. |
| Unused local variables `bed_charge`, `base_bill`, `p` (Flake8 F841, Pylint W0612) | Code Quality (Low) | 29, 39, 61 | `bed_charge` is never used, `base_bill` is used only via `eval` (hidden dependency), and the loop variable `p` is unused. | Delete `bed_charge`. Use `base_bill` explicitly once `eval` is removed. Loop with `for details in patient_records.values():`. |
| Comparison to `None` with `==` (Flake8 E711, Pylint C0121) | Code Quality (Low) | 30 | `patient_records.get(p_id) == None` should use identity. | Use `is None`, or simply `if p_id not in patient_records:`. |
| Redundant `if/else` returning a bool (Pylint R1703, R1705) | Code Quality (Low) | 32–35 | `if x: return True else: return False` is just `return x`. | `return bool(patient_records[p_id]["is_admitted"])`. |
| Function shadows global `patient_records` (Pylint W0621) | Code Quality (Low) | 59 | The parameter has the same name as the module-level dict, which is confusing and error-prone. | Rename the parameter to `records`. |
| `get_ward_summary` only counts admitted patients | Bug / Naming (Low) | 59–64 | The name implies a per-ward summary but it returns one total count. The variable `c` is cryptic. | Rename to `count_active_admissions`, or actually group counts by ward. Use `sum(1 for d in records.values() if d["is_admitted"])`. |
| Unused import `math` (Flake8 F401, Pylint W0611) | Style (Low) | 4 | `math` is imported but never used. | Delete the import. |
| `main()` runs on import, no `__main__` guard | Code Quality (Low) | 80 | Importing the module executes the whole demo, which makes testing impossible. | Wrap the call in `if __name__ == "__main__":`. |
| Function name `admitPatient` not snake_case (Pylint C0103) | Style (Low) | 13 | Violates PEP 8 naming and is inconsistent with the other functions. | Rename to `admit_patient` and update the call in `main()`. |
| String formatting with `%` (Pylint C0209) | Style (Low) | 17 | Old-style formatting where an f-string is clearer. | `f"Admitted patient {p_id} into ward {ward}"`. |
| Missing module and function docstrings (Pylint C0114, C0116) | Style (Low) | 1, 13, 21, 28, 38, 44, 48, 52, 59, 67 | No documentation for the module or any function. | Add a module docstring and a short docstring to each function (purpose, args, return). |
| Lines longer than 79 characters (Flake8 E501) | Style (Low) | 7, 8, 9, 16, 72 | Records dict entries, the `patient_records[...]` assignment and a print line exceed the limit. | Break the dict entries across lines, split the long statements, or use shorter intermediate variables. |
| Missing newline at end of file (Flake8 W292, Pylint C0304) | Style (Low) | 80 | File does not end with a newline. | Add a trailing newline. |
